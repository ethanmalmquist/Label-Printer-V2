barcode-core test harness

Exercises the barcode-core library's three value strategies, ZPL emission, and selected-barcode resolution.

1. Stored barcode (Equipment / Product style)

2. Computed barcode (Location style: Aisle + Bay + Level + Bin)

3. Random unique barcode (Product style)

4. Selected-barcode resolution

Sample rows: 111111111111 (Widget A), 222222222222 (Widget B), 333333333333 (Widget C).
